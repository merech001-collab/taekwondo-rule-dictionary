# 태권도 경기규칙 전자사전

태권도 심판, 지도자, 선수, 대학생이 경기규칙을 빠르게 검색하고 이해할 수 있도록 만든 웹 전자사전 프로젝트입니다.

## 1차 시제품 기능

- 경기규칙 키워드 검색
- 조항별 목차
- 주제별 분류
- 규정 원문 / 쉬운 해설 / 심판 핵심 / 판정 사례 구조
- 즐겨찾기(LocalStorage)
- 최근 검색(LocalStorage)
- 모바일 반응형 화면

## 중요

현재 등록된 규정 내용은 모두 **샘플 데이터**입니다. 실제 대한태권도협회 공식 경기규칙 PDF 또는 문서를 입력한 뒤 조항별 원문과 해설로 교체해야 합니다.

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 동작합니다.
